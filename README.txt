IKFY RMX STORE

Isi folder:
- index.html : halaman utama website
- audio/     : tempat menyimpan file audio preview

PENTING:
Di index.html, alamat file audio saat ini masih memakai path komputer lokal Windows
(C:\\Users\\...). Path tersebut tidak akan berfungsi saat website di-hosting.

Sebelum dipublikasikan:
1. Letakkan file audio yang ingin diputar di folder audio/.
2. Ubah nilai `file` pada daftar `songs` di index.html menjadi path relatif,
   misalnya: `audio/nama-lagu.mp3`
3. Upload index.html dan folder audio ke root repository GitHub.
4. Aktifkan GitHub Pages melalui Settings > Pages > Deploy from a branch > main > /(root).

Catatan:
ZIP ini memakai file HTML yang baru saja kamu kirim. Kode dan desain halaman dipertahankan.
